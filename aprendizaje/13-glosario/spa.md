# SPA

Single-Page Application (aplicación de una sola página). El navegador carga una sola página HTML y el resto del contenido se intercambia por JavaScript sin recargar el navegador al navegar.

En este proyecto, React Router maneja las rutas (`/`, `/servicios`, `/nosotros`, `/contacto`) dentro de la misma página.
