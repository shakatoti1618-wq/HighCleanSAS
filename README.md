# High Clean SAS

Web profesional para High Clean SAS: publicitar la empresa y mostrar sus servicios.

## Stack

- **Frontend**: React + TypeScript + Vite + React Router (+ Tailwind CSS)
- **Backend**: Node.js + Express + TypeScript
- **Base de datos**: PostgreSQL + Prisma
- **Validación**: Zod
- **Testing**: Vitest + Supertest + React Testing Library

## Estructura

```text
app/
  frontend/   # Aplicación React (SPA)
  backend/    # API REST Express
docs/         # Arquitectura, API, deploy, seguridad, SEO, decisiones, módulos
aprendizaje/  # Aprendizaje por conceptos (13 áreas + glosario)
```

## Reglas y convenciones

El desarrollo se guía por `AGENTS.md` y `.agents/rules/`. No se hace `git push` sin autorización explícita.
